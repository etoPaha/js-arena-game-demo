# Arena — демо

Браузерная дуэль на мечах с врагом-нейросетью (Three.js + Rapier).

**Играть:** https://etopaha.github.io/js-arena-game-demo/

- клик по игре — захватить мышь (Esc — отпустить), WASD — движение, мышь — взгляд, ЛКМ — удар (наклон камеры — высота удара), пробел — перекат, E — поднять меч
- 1–6 — сменить врага (скриптовый, нейросети), R — заново, P — пауза, M — звук
- [Просмотрщик анимации](https://etopaha.github.io/js-arena-game-demo/?animview)

Здесь только собранная игра. Анимации-референсы — Mesh2Motion (CC0).
